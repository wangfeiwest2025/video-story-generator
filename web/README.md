# 🎬 AI短视频生成器 - Streamlit Web界面

一个直观的Web界面，让非技术用户也能轻松创建AI短视频。

## 🌟 功能特性

### 📝 脚本编辑
- **在线编辑**: 直接在网页上创建脚本
- **文件上传**: 上传JSON格式的脚本文件
- **示例模板**: 使用现成的示例快速开始

### 🎥 视频参数调整
- **分辨率选择**: 960x544 / 1344x768 / 1920x1080
- **质量调节**: 15-30步采样控制
- **TTS语音**: 三种中文语音选择

### 🎵 音频控制
- **解说词音量**: 80%-150%调节
- **环境音音量**: 20%-80%调节

### 📊 实时监控
- **生成进度**: 实时显示每个阶段进度
- **队列状态**: 查看ComfyUI队列
- **自动刷新**: 自动更新进度信息

### 🎥 结果预览
- **在线预览**: 直接在网页预览视频
- **一键下载**: 下载最终视频或单场景视频

## 🚀 快速开始

### 1. 安装依赖

```bash
cd web/
pip install -r requirements.txt
```

### 2. 启动应用

```bash
streamlit run app.py
```

### 3. 访问界面

浏览器自动打开 `http://localhost:8501`

## 📖 使用指南

### 第一步：创建脚本

选择三种方式之一：

#### 方式1: 在线编辑
1. 输入视频标题和风格
2. 设置场景数量
3. 为每个场景填写：
   - 解说词（中文）
   - 视觉描述（英文）
   - 音频描述（环境音、音乐）
4. 点击"生成脚本"

#### 方式2: 上传文件
1. 准备JSON格式脚本
2. 点击上传
3. 系统自动加载

#### 方式3: 使用模板
1. 选择示例模板（科幻/自然等）
2. 点击加载
3. 可选：修改后使用

### 第二步：调整参数

在侧边栏调整：

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 分辨率 | 视频尺寸 | 1344x768 |
| 采样步数 | 质量 vs 速度 | 20 |
| 解说词音量 | 主音量 | 120% |
| 环境音音量 | 背景音量 | 50% |

### 第三步：开始生成

1. 切换到"🚀 生成控制"标签
2. 确认脚本和参数
3. 点击"🚀 开始生成"
4. 等待自动完成

### 第四步：监控进度

在"📊 进度监控"标签查看：
- 总体进度
- 各阶段状态
- ComfyUI队列
- 实时更新

### 第五步：预览和下载

在"🎥 结果预览"标签：
- 在线预览视频
- 下载最终视频
- 下载单场景视频

## 🎯 最佳实践

### 脚本建议
- **场景数**: 5-12个最佳
- **单场景时长**: 8-15秒
- **总时长**: 1-3分钟

### 视觉描述
- 使用英文
- 包含光线、镜头、风格
- 详细描述主体和动作

### 音频描述
- 描述环境音效
- 指定音乐类型
- 增强场景氛围

## ⚙️ 配置要求

### 后端要求
- **ComfyUI**: 需要运行在 `http://localhost:8188`
- **MiniMax H3**: 已安装所需模型
- **ffmpeg**: 系统已安装

### 硬件要求
- **GPU**: NVIDIA RTX 3090+ (24GB+ VRAM)
- **内存**: 32GB+
- **存储**: 100GB+

## 🔧 高级配置

### 修改ComfyUI地址

编辑 `app.py`:

```python
# 默认
comfyui_url = "http://localhost:8188"

# 修改为你的地址
comfyui_url = "http://your-server:8188"
```

### 自定义参数范围

编辑参数滑块的最小/最大值：

```python
steps = st.slider(
    "采样步数",
    min_value=10,  # 修改最小值
    max_value=50,  # 修改最大值
    value=20
)
```

## 🐛 故障排除

### Q: ComfyUI连接失败？
**A**: 确保ComfyUI正在运行在 `http://localhost:8188`

### Q: 生成速度慢？
**A**: 降低分辨率或采样步数

### Q: 视频质量差？
**A**: 增加采样步数，优化视觉提示词

### Q: 端口8501被占用？
**A**: 使用其他端口：
```bash
streamlit run app.py --server.port 8502
```
